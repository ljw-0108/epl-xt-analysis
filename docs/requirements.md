# 4주 프로젝트 요구사항 — EPL 2025/26

## 목표
공식 릴리스의 실제 2025/26 EPL 패스 이벤트를 안전하게 다운로드하고 팀 패스 위치, 패스 기반 xT 및 핵심 선수 분석 기능을 구축한다. 2026/27 결과 데이터와 이벤트 데이터를 합쳐 분석하지 않는다.

## MVP
- [x] 25/26 원본 파일 다운로드·SHA-256 검증·컬럼 변환 코드 (실제 다운로드는 인터넷 연결된 PC에서 수행)
- [x] 팀/경기 필터, 실제 패스 위치 지도, 선수별 xT 및 2인 비교 Streamlit 코드
- [x] 출처와 xT 표면 연식, 수신자 누락 한계 노출
- [ ] 사용자 PC에서 원본 다운로드 실행 및 실제 파일 검증
- [ ] **정확한 선수 간 패스 네트워크**: 데이터에 수신자 필드 없음. 보수적 추정 네트워크를 만들 경우 추정치로 별도 표시하고 신뢰성 평가 필수.
- [ ] 재현성 검수, 보고서/발표 정리

## 분석 범위
- xT = 성공 패스의 xT(도착) - xT(시작), 부호 유지.
- 선수 간 연결 데이터가 없을 때는 패스 위치 지도를 제공하고 가상 연결값은 금지.
- 선수 비교는 동일한 팀·경기 필터를 따름.
