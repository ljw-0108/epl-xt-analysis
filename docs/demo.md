# 시연 순서 (약 5분)

준비: `python scripts/download_openplay_2526.py` → `streamlit run app.py`. 아래 수치는 2026-11-25 실데이터로 확인한 값이다.

1. **데이터 신뢰성 (30초)** — 상단 출처 표기와 하단 SHA-256·검증 방식을 보여준다. "원본 체크섬 검증, 380경기 · 패스 362,739건, 제외 0건 (`docs/data_quality_report.md`)."
2. **팀 선택 → 경기 선택 (1분)** — 사이드바에서 `Arsenal`, 경기 범위 `경기 선택` → `vs Man Utd · 1903125`.
   - ① 패스 지도: 💡 한눈에 보기 문장과 카드(패스 시도 329, 성공 239(72.6%), 전진 패스 28)를 읽어준다. 지도의 파란 선 = 성공, 주황 = 실패. 점에 마우스를 올려 선수 이름이 뜨는 것을 보여주고 `전진 패스`로 전환.
   - 방향 분포: 전진 141 / 횡 153 / 후진 35.
3. **xT (1분 30초)** — ② 위협 지도 (xT): 맨 위 한 줄 설명으로 xT를 소개한 뒤, 위협 점수 합계 0.761 (+0.942 / −0.181). ‘어디서 보낸 패스가 위협을 만들었나’ 지도에서 파랑 = 증가, 빨강 = 감소, 칸에 마우스를 올리면 구역 이름이 뜬다. `구역별 기본 위협 값 (xT 그리드)`로 값이 상대 골문 쪽으로 커지는 것을 보여준다. 같은 경기 상대팀(Man Utd 0.836)과 비교.
   - 사이드바 `패스 범위 = 오픈플레이만`(경기 범위 `시즌 전체`): Arsenal xT 46.290 → 32.688, 패스 시도 19,417 → 17,910. 코너 지점 히트맵 값이 사라지는 것을 보여준 뒤, 다시 `전체 패스`와 `경기 선택`(vs Man Utd)으로 돌린다.
   - 한계 언급: 공개 그리드 재사용(25/26 재학습 아님), 승리 확률 예측 아님, 킥오프는 원본 플래그가 없어 오픈플레이에 포함.
4. **두 선수 비교 (1분)** — ③ 선수 비교: 선수 A `Declan Rice` vs B `William Saliba`, 💡 문장(패스 시도는 Declan Rice 쪽이 1번 더 많음 …)과 막대·표. 순위 기준은 `위협 점수 합계 (xT)`. 같은 경기 필터가 적용됨을 보여주고, 경기 범위를 `시즌 전체`로 바꾸면 두 선수 수치가 함께 바뀐다(Rice 시즌: 시도 2,363 · 전진 185 · xT 9.948).
