# 4주 프로젝트 요구사항 — EPL 2025/26

## 목표
공식 릴리스의 실제 2025/26 EPL 패스 이벤트를 안전하게 다운로드하고 팀 패스 위치, 패스 기반 xT 및 핵심 선수 분석 기능을 구축한다. 2026/27 결과 데이터와 이벤트 데이터를 합쳐 분석하지 않는다.

## MVP (상태: 2026-11-25, 근거는 `docs/claude_harness_plan.md`)
- [x] 25/26 원본 파일 다운로드·SHA-256 검증·컬럼 변환 코드
- [x] 원본 다운로드 실행 및 실제 파일 검증 (380경기, 패스 362,739건, 제외 0건 — `docs/data_quality_report.md`)
- [x] 팀/경기 패스 분석: 필터, 전체 패스 지도, 방향 분포, 전진 패스
- [x] xT 분석: 고정 해시 그리드, 부호 유지 패스 xT, 팀 집계, 위치별 히트맵, 별도 구현과 일치 확인
- [x] 선수 비교: 같은 필터의 2인 비교, 순위, 누락 선수 처리
- [x] 출처와 xT 표면 연식, 수신자 누락 한계 노출
- [x] (선택) 필터된 패스 CSV 내려받기
- [ ] **정확한 선수 간 패스 네트워크**: 데이터에 수신자 필드 없음 → 범위에서 제외. 추정 네트워크를 만들 경우 추정치로 별도 표시하고 신뢰성 평가 필수.
- [ ] 배포 URL (Streamlit Community Cloud: 시작 시 다운로드 스크립트 실행 방식 설계 필요)

## 분석 범위
- xT = 성공 패스의 xT(도착) - xT(시작), 부호 유지.
- 선수 간 연결 데이터가 없을 때는 패스 위치 지도를 제공하고 가상 연결값은 금지.
- 선수 비교는 동일한 팀·경기 필터를 따름.
