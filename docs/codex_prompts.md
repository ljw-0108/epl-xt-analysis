# Codex에 붙여 넣을 순서별 프롬프트

## 1. 프로젝트 점검
AGENTS.md, README.md, docs/data_sources.md, docs/data_contract.md, docs/requirements.md를 먼저 읽어줘. 사용자가 2026/27 경기 이벤트를 확보하지 못할 경우 2025/26으로 전환해도 된다고 승인했어. 따라서 이 프로젝트의 **전술 분석 시즌은 2025/26**이고 데이터 제공자는 openplay (Noah Bair)야. 26/27 결과표는 별도 보관하고 절대 합치지 마. 구현 현황과 한계를 먼저 확인하고 pytest를 실행해. 인터넷 연결이 있으면 python scripts/download_openplay_2526.py를 실행해 SHA-256이 맞는지 확인하고 실제 25/26 경기 수·선수 수·패스 건수를 보고해. 실패하면 이유와 해결 방안만 보고하고 가짜 데이터를 생성하지 마.

## 2. 실제 데이터 품질 검증
OpenPlay DATA_DICTIONARY.md와 다운받은 실제 events_eng_2526.parquet을 비교해줘. Pass 이벤트 중 좌표 결측, outcome 누락, 경기별 패스 건수를 점검하고 data_issues.csv, known_gaps.csv의 25/26 EPL 해당 항목도 확인해. 누락 경기와 행을 숨기지 말고 앱에 품질 보고서를 추가해줘. 테스트를 작성하고 통과시켜.

## 3. 네트워크 기능 개선 (추정과 실제 구별)
OpenPlay Pass 이벤트에는 원본 수신 선수 정보가 없어 현재는 정확한 선수→선수 패스 네트워크를 표시하지 않는다고 AGENTS.md에 적혀 있어. 먼저 명확히 확인하고, 가능하면 후속 동일 팀 볼 터치 이벤트와 패스 도착 위치·시각을 이용해 보수적인 수신자 추정 방법을 설계해줘. 직접 확인된 수신자와 **추정 수신자**를 절대 혼동하지 마. 수신자를 추정할 때는 보류/불명으로 남기는 기준도 만들어줘. 추정 정확도를 따로 평가할 수 있는 근거가 없다면 팀 패스 공간분포만 유지해. 무분별한 자동 연결을 하지 마.

## 4. 시각화 및 발표
실제 25/26 EPL 데이터를 기반으로 Streamlit 대시보드에 패스 지도, 팀/경기 필터, 성공 패스 xT 랭킹, 두 선수 비교를 개선해줘. xT 그리드는 2017/18 EPL 기준 공개 12x8 Karun Singh 그리드이고, 25/26로 재학습한 것이 아니라고 명시해. 최소한 pytest, 데이터 무결성, 빈 필터, xT 계산 테스트를 확인하고 한계와 출처를 발표용 문서로 정리해.
